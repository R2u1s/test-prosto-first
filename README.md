# Тест скорости интернета

Консольная утилита на Node.js для последовательного тестирования скорости интернета по заданному URL.

Скрипт выполняет серию последовательных HTTP/HTTPS-запросов (по умолчанию 10), дожидается полной загрузки тела каждого ответа, считает среднее время выполнения запроса, общий объём полученных данных и вычисляет итоговую скорость скачивания. Результат выдает в трех единицах измерения: мебибайт/сек, мегабайт/сек, мегабит/сек

## Требования

- **Node.js** версии **18.17.0** или выше (рекомендуется Node.js 20 / 22 LTS).
- Внешние зависимости **не требуются** (Zero-dependencies — используются только встроенные модули Node.js).

## Установка и запуск

1. Склонируйте репозиторий:
   git clone https://github.com/R2u1s/test-prosto-first.git
   cd test-prosto-first

2. Запустите скрипт, передав целевой URL:
   node index.js <тестируемый URL>

   Например:
   node index.js https://github.com/R2u1s/R2u1s

3. Запуск для очень большого файла с ограничением объёма одного скачивания до 10 MiB:
   node index.js <тестируемый URL> --max-size=10

   Например:
   node index.js https://telegram.org/dl/desktop/win64 --max-size=10
